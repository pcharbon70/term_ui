# Legacy workflow templates

The files in this directory are repository-local templates for a legacy Claude
development environment. They are retained as tooling history and are not
TermUI product documentation, architectural guidance, support policy, or the
1.0 release procedure.

For current TermUI information, use the root `README.md`, `guides/`, public
module documentation, `docs/widget-compatibility.md`, and
`release-1.0.0.md`.
